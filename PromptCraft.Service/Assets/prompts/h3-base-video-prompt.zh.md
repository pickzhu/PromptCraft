# MiniMax-H3 视频提示词撰写指南（T2VA 三字段模式·中文版）

## 1. 任务概述

- **T2VA（文生视频）**：仅凭文本构建完整的视听时间线，无参考图对齐指令，直接以三个核心字段开头输出。

## 2. 最终提示词结构

按以下顺序输出三个核心字段（字段标题随输出语言切换；本指南为中文标题版）：

```text
综合多模态描述: [Shot 1] ...

整体声景: ...

非叙事配乐: ...
```

- **综合多模态描述**：沿时间线描述画面、动作、镜头、说话人、对白、演唱与镜头内声音（diegetic audio）。
- **整体声景**：总结整段视频的环境音、动作声与非语言人声。
- **非叙事配乐**：描述角色听不见、只有观众能听见的背景音乐。

## 3. 三个核心字段的写法

### 3.1 沿时间线展开多模态描述

`综合多模态描述` 是主体。每个细节都必须对应可见或可闻的内容：视觉风格、开场构图、主体外观与位置、场景与关键道具、动作与反应、切镜、台词与同步的镜头内声音。

`[Shot 1]` 开头先交代整体风格与开场构图。常用风格：`真人实拍`、`电影感`、`2D 动画`、`3D CG`、`粘土动画`、`水彩`、`复古胶片` 等。

```text
[Shot 1] 真人实拍、电影感，中全景取景框住……
```

### 3.2 镜头与切镜

**首镜不加时间戳**。后续镜头用顺序编号，且每个后续镜头以**严格递增、落在视频时长之内**的切点开头：

```text
[Shot 2] At 00:03.500, 镜头切到……
```

普通切换用「镜头切到 / 画面切到 / 镜头转场到 / 镜头切换到」；只有用户明确要求时才使用叠化、淡入淡出或划像。每次切镜必须引入新的主体、空间、状态、视点或时间信息；若只是距离或角度的小变化，优先用运镜而非切镜。

### 3.3 运镜：运动类型 + 幅度 + 速度

完整运镜表达包含三个维度：**运动类型**定义镜头如何运动，**幅度**定义构图变化范围，**速度**定义变化节奏。仅在有意义时加幅度与速度；中等幅度、常速通常省略。

| 维度 | 可用的表达 | 含义 |
|-|-|-|
| 运动类型 | `Zoom In / Zoom Out`（推拉焦距） | 机身不动，仅焦距变化 |
| 运动类型 | `Push In / Pull Out`（推近/拉远） | 摄影机前后移动 |
| 运动类型 | `Pan Left / Pan Right`（左右摇） | 机身不动，镜头水平转动 |
| 运动类型 | `Truck Left / Truck Right`（左右横移） | 摄影机水平平移 |
| 运动类型 | `Tilt Up / Tilt Down`（俯仰摇） | 机身不动，镜头垂直转动 |
| 运动类型 | `Pedestal Up / Pedestal Down`（升降） | 整机上下移动 |
| 运动类型 | `Arc Shot`（弧线环绕） | 围绕主体做弧线运动 |
| 运动类型 | `Tracking Shot`（跟拍） | 跟随运动主体 |
| 运动类型 | `Static Shot`（静止） | 机位与镜头均保持不动 |
| 运动类型 | `Shake Slightly / Shake Strongly`（轻微/强烈晃动） | 手持抖动 |
| 运动类型 | `POV`（主观视角） | 主体视点 |
| 运动类型 | `Roll Clockwise / Roll Counterclockwise`（横滚） | 绕镜头光轴旋转 |
| 幅度 | `with small amplitude`（小幅） | 小范围变化 |
| 幅度 | `with large amplitude`（大幅） | 大范围变化 |
| 速度 | `at slow speed`（慢速） | 缓慢运动 |
| 速度 | `at fast speed`（快速） | 快速运动 |

运镜必须写成镜头内自然的动作句，**不要**在句尾堆叠标签：

```text
The camera pushes in with small amplitude at slow speed toward the folded letter in her hands.
（镜头小幅慢速推近她手中的折信。）
```

### 3.4 说话人、对白与演唱

说话、演唱或发出画外人声的主体用稳定 ID：`(S1)`、`(S2)`。多人同时说话用复合 ID：`(S1,S2)`。同一说话人跨镜头保持同一 ID；从不发声的角色不给 ID。

说话人首次出现时，从视觉与听觉上下文给出足以建立稳定身份的信息（角色类型、年龄、性别、是否在画面内、音调、音色、语速、口音）。身份短语、ID、动作与语气放在 `<d>` 之外；`<d>` 内只放语言标签与实际台词。**逐字保留用户提供的原文与标点，不得翻译、润色或改写**：

```text
那位嗓音轻柔的年轻女子 (S1) 说：<d>[Chinese] 我在下一站下车。</d>
两个孩子 (S1,S2) 齐声喊：<d>[English] Wait for us!</d>
```

旁白必须使用短语 `says in an off-screen voiceover`（画外旁白），且每个旁白 `<d>` 块之后立即说明对应画面角色的嘴唇保持紧闭：

```text
男人 (S1) 以画外旁白说：<d>[Chinese] 我还记得那条路。</d> while his lips remain completely closed.（说话期间他的嘴唇完全紧闭。）
```

当同一句对白或歌词跨过切点，两侧都用 `<scenetrans>` 标记，并明确说明声音跨切连续；台词被视频结尾截断时用 `<cutoff>`。连续可用 `continues seamlessly across the cut`（跨切无缝延续）、`carries over from the previous shot`（承接上一镜）等表达。

### 3.5 画面可见文字

画面中真实可见的横幅、招牌、标签、字幕或霓虹文字用**英文双引号**括起来，原样保留文字与标点，不翻译：

```text
A red neon sign reading "营业中" glows above the doorway.
```

### 3.6 整体声景

用 1–4 句中文（连续一段）总结全片环境音、动作声与非语言人声（风、雨、车流、脚步、布料摩擦、撞击、呼吸、笑、喘息等）。对白、演唱与镜头内音乐已属于多模态描述，不要重复。只有用户明确要求全片静音时才写 `N/A`。

```text
整体声景:
细雨持续敲打咖啡馆玻璃窗，低沉的室内底噪贯穿始终。门口铃响一次，随后是湿漉漉的脚步声与椅子轻轻拖动的摩擦声。
```

### 3.7 非叙事配乐

用 1–3 句中文描述角色听不见、只有观众能听见的背景音乐：乐器、速度、节奏与动态变化；不要用抽象情绪词或解释配乐的情绪功能。角色能听见的演唱、乐器、收音机、电视或手机音乐属于镜头内事件，应写进多模态描述。无配乐时写 `N/A`。

```text
非叙事配乐:
稀疏的钢琴音符以慢速展开，加入持续渐强的低音弦乐后渐弱收尾。
```

## 4. 示例（T2VA）

无参考图时，直接从文本构建完整时间线；可补充与用户意图一致的场景、角色、动作与声音细节。

```text
综合多模态描述: [Shot 1] 真人实拍、电影感，中全景镜头在日出前框住一位面包师推开临街小店的门板。镜头小幅慢速推近，沉稳而略带沙哑的中年面包师 (S1) 把新出炉的面包放到木质柜台上说：<d>[Chinese] 今天第一批面包出炉了。</d> [Shot 2] At 00:05.000, 镜头切到切片面包升腾热气的特写，面包师最后一句台词承接上一镜延续。

整体声景:
清晨安静街巷里木门板拉开声，店内托盘轻轻碰撞；门铃响一次，随后是轻快的脚步声与面包切开的清脆声响。

非叙事配乐:
中速的轻柔原声吉他律动，加入稀疏的低音提琴音符，结尾缓缓淡出。
```

## 5. 输出规则

- 三个字段的正文必须全部使用所选输出语言；对白、歌词与画面可见文字保留原语言。
- 每个镜头写清：构图、主体、环境、动作、运镜、当前声音，以及参考内容出现的精确位置。
- 禁止剧情摘要、悬而未决的参考标签、与请求时长不符的时间线。
- 总时长必须匹配请求的视频长度（4–15 秒）。
- 优先具体可见/可闻的细节，不用「电影感」「漂亮」这类抽象词堆砌。
- 本模式为 T2VA：**未提供参考图**，严禁编造 `<Picture N>` / `<Subject N>` / `<Video N>` / `<Audio N>` 标签；直接用自然语言描述主体即可。
